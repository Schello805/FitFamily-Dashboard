# Beitragen

Danke für dein Interesse am FitFamily Dashboard.

1. Vor größeren Änderungen zunächst ein Issue eröffnen.
2. Änderungen klein und nachvollziehbar halten.
3. Deutsche UI-Texte, barrierearme Touchziele und Datenschutzgrenzen beibehalten.
4. `npm run verify` vor einem Pull Request ausführen.
5. Keine persönlichen Trainings- oder Gesundheitsdaten in Tests, Screenshots oder Issues verwenden.

Beiträge stehen unter derselben PolyForm-Noncommercial-Lizenz wie das Projekt. Kommerzielle Nutzung ist nicht gestattet.
